# 材料缺陷检测一体化应用 —— 需求分析（整理版）

## 一、总体概述

集成「人工标注 → 数据集划分 → 模型训练 → 推理检测」四大功能的一站式桌面应用。
用户只需要导入收集到的图片，即可在应用内完成全部后续操作。

**技术栈**：PySide6 桌面应用 + Ultralytics YOLO26

---

## 二、启动界面（双击应用后的首页）

### 布局

```
┌──────────────────────────────────────────────┐
│ ┌─────────────────────┐     [新建项目]        │
│ │  历史项目列表        │     [打开项目]        │
│ │  （最近打开过的项目，│                      │
│ │    点击即可进入）    │    GitHub 仓库链接    │
│ └─────────────────────┘                      │
└──────────────────────────────────────────────┘
```

### 功能说明

| 按钮 | 行为 |
|------|------|
| **新建项目** | 创建一个新的项目文件夹，后续所有操作（导入数据、标注、训练、检测）都在该文件夹内进行 |
| **打开项目** | 打开已有的项目文件夹，后续所有操作同样在该文件夹内进行 |
| **历史项目** | 显示最近打开过的项目列表，点击即可直接进入 |
| **GitHub 链接** | 跳转 https://github.com/mJxCreator/YOLO |

## 三、项目主界面（进入项目后）

### 3.1 整体布局

- **顶部导航栏**：`[三] [文件] [编辑] [帮助]`
- **主内容区**：默认显示「标注界面」

### 3.2 侧边栏（点击 `[三]` 三横线图标展开）

包含三个页面入口：

1. 标注界面
2. 训练界面
3. 检测界面

### 3.3 文件菜单 `[文件]`

| 菜单项 | 说明 |
|--------|------|
| 打开其他项目 | 切换到另一个项目文件夹 |
| 导出模型（ONNX/TensorRT） | 导出训练好的模型 |
| 导出标注 | 导出标注数据 |

### 3.4 编辑菜单 `[编辑]`

- 个性化设置（主题、快捷键等）

### 3.5 帮助菜单 `[帮助]`

- 进入 GitHub（跳转仓库链接）

## 四、标注界面（默认页面）

**设计原则：模仿 LabelImg 的交互方式，快捷键等尽量参考 LabelImg。**

### 功能需求

1. **图片浏览**：加载并浏览项目文件夹中的图片
2. **画框标注**：鼠标拖拽在图片上画矩形框，标记缺陷位置
3. **类别管理**：选择/新建缺陷类别（如 crack、scratch 等）
4. **标注编辑**：移动、缩放、删除已画的框；修改框的类别
5. **数据保存**：标注结果保存为 YOLO 格式（.txt 标签文件）
6. **快捷键**：参考 LabelImg 常用快捷键（下一张/上一张、保存、删除框等）

## 五、训练界面

*（用户未见过，由开发者设计，建议包含：）*

1. **数据集划分**：一键按比例（如 80/20）划分训练集和验证集
2. **训练参数配置**：训练轮数、批次大小、图片尺寸、学习率等
3. **设备选择**：自动检测 GPU/CPU，有 GPU 用 GPU 训练
4. **训练进度**：实时显示当前轮次、loss、mAP 等指标
5. **训练日志**：实时滚动显示训练输出日志
6. **训练控制**：开始/停止训练

---

## 六、检测界面

*（用户未见过，由开发者设计，建议包含：）*

1. **图片检测**：选择单张图片或整个文件夹进行检测
2. **视频检测**：选择视频文件进行检测
3. **摄像头检测**：连接 USB 摄像头进行实时检测（可选功能）
4. **结果展示**：在图片/视频画面上标注缺陷框和类别
5. **结果保存**：保存检测结果图片/视频及检测报告
6. **模型选择**：选择使用哪个训练好的模型进行检测
